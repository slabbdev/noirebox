# Code of Conduct — the short version

This project exists to demonstrate that a security tool can be honest:
real metrics, documented limits, zero theater.

1. Be precise and kind — criticism is about the code, never the people.
2. No fake demos: an unrepeatable metric is a bug, not an argument.
3. Security topics (attacks, bypasses) are discussed here on test targets — never on real systems.
4. English and French are both welcome; both healthy wording and poisoned wording should remain polite. 😉
5. If there is a disagreement, an ADR decides — not authority, not a loud voice.

Inspired by the Contributor Covenant; any violation may be reported to the maintainer
(see SECURITY.md for contacts).
